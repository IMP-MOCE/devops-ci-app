# Развёртывание на devops-vm

Учебный образ: `ghcr.io/imp-moce/devops-ci-app`. GHCR разрешает анонимную
загрузку этого публичного пакета. На devops-vm используется SSH-пользователь
`devops` и установленный Docker Engine. Адрес учебного узла задаётся в inventory.

Выбирайте полный SHA из успешного запуска на `main`. Первый проверенный
вариант опубликован как `28a22a06eb97f22bbf044d494eb016834d667e67`.
Для строгой привязки к содержимому используйте соответствующий digest
`sha256:614010d929abe7c47846f6ea4b93e71d91f04ba146bf72a5cdaa0f9cfd1399ed`.

Приложение слушает 5000 внутри контейнера. Для локальной проверки
можно связать `127.0.0.1:5001` с портом 5000 контейнера. Проверка
готовности — `GET /health`, HTTP 200 и `{"status":"ok"}`. В будущем
Ansible playbook загружает проверенный образ из реестра и обеспечивает
требуемое состояние контейнера. Повторная сборка на VM не требуется.
